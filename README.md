# True Concept - Technology Solutions Web Application

This repository contains the full application source and a static GitHub Pages preview.

## Running locally

Requires Node.js and SQLite.

```bash
npm install
npm start
```

Default admin login:
- Email: `admin@trueconcept.com`
- Password: `admin123`

## Preview link

The static demo for team review is served from the `gh-pages` branch.
